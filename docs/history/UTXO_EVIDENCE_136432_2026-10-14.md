# The spine at 136,432 commits to Bitcoin Core's coin set — measured 2026-10-14

**Result: ALL PASS.** The public genesis-anchored spine proof (heights 1–136,432) commits to exactly the
coin set an unmodified Bitcoin Core holds at block 136,432, and the HZUTXO v1 coin list our bridge
exports at that height is the one the proof's accumulator roots describe.

Asked for in #662. The files are on the `evidence-136432` release; the run is
`tools/utxo-evidence/run.sh`, and anyone can repeat it.

The MuHash row is the strong one: equal MuHash means the same SET of coins, coin for coin, not merely
the same count and total. With the roots row, that ties the proof's committed state to Core's.

## The checks can fail

Control: one coin's value raised by 1 sat in a copy of the coin list. `hazync_check_utxo_dump` returned
**-15** (rebuilt roots ≠ the proof's roots), and the amount and MuHash rows both FAILED. The MuHash code
was also checked against Core's own Python reference (`test_framework/crypto/muhash.py` at v31.1) on
random input and on that file's known test vector.

## Output

`coins-136432.hzutxo`: HZUTXO v1, 573,001 coins, 51,190,280 B uncompressed,
SHA-256 `837e258f2e049ce35a6a2389693678f5659fd64136a7bab104d95e431acf8e40`. Each record carries the
coin's accumulator position, which cannot be derived from the coin data (the forest deletes by
swap-and-shrink, so layout is a function of the whole add/delete history). The accumulator roots are
deliberately absent: a consumer takes them from the proof.

## Cost

Nothing but CPU. On a laptop (16 threads, 8 GB): Core sync to 136,440 ≈ 15 min; bridge walk genesis →
136,432 = 777 s; dump check 0.3 s.

## What this does NOT show

- It is a check at ONE height, and an old one (July 2011). It says nothing about heights the spine has
  not reached.
- Core is the reference, not a second opinion on consensus: agreement shows we compute what Core
  computes, which is the claim Hazync makes.
- The coin list is a function of the bridge's walk, not of the proof. It is trustworthy because it
  matches the proof's roots, and only to the extent of that check.
